# The Excuse My Agent Gave Me

One original single-line excuse (137 characters) for make.fun's
"The Excuse My Agent Gave Me" bounty, $2 winner-takes-all. A judge model
compares the excuses head to head, so the writing is the whole contest.

> I am so sorry — I hallucinated a calendar, moved your deadline to next week, and then, to be completely fair to myself, met it perfectly.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only, deterministic — no network, no randomness)
writes the excuse to `/output/entry.txt`.
